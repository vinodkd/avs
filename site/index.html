How it works

  1. 1
    Load

    Point it at an SD card or folder. It finds your clips and extracts metadata.

  2. 2
    Analyze

    Generates proxy files, detects scenes, scores clips by motion and telemetry. Supports GoPro GPMF and DJI SRT data.

  3. 3
    Review

    Browse thumbnails sorted by activity score. Mark clips to include or skip.

  4. 4
    Assemble

    Combines selected clips, applies a color grade and music from a sport preset, renders a preview.

  5. 5
    Export

    Final H.264 encode in one or more aspect ratios — 16:9, 9:16, 1:1.

No timeline scrubbing. No effects panels. The computer edits; you approve.

Install

Linux

Download the AppImage, make it executable, run it.

chmod +x AxEdUp-*.AppImage
./AxEdUp-*.AppImage

On minimal installs: sudo apt install libgtk-3-0 libwebkit2gtk-4.0-37

Download AppImage

Windows

Run the installer. Standard Next → Next → Install wizard. No dependencies required.

Download Installer

macOS

Open the DMG, drag AxEdUp to Applications. On first launch, right-click → Open to pass Gatekeeper (one time only).
